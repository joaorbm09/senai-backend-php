## Conceitos

- **Interface:** define um contrato com os métodos que uma classe deve oferecer, sem determinar como eles serão executados.
- **Classe abstrata:** pode guardar atributos e código compartilhado, além de declarar métodos que as subclasses precisam implementar. Uma interface define o contrato; uma classe abstrata também pode fornecer implementação.
- **Trabalho em equipe:** o contrato permite que diferentes pessoas implementem classes distintas com os mesmos métodos, facilitando o uso delas sem depender de detalhes internos.
