1. Explique com suas palavras o que é herança.

A herança é um termo que utilizamos para um classe herdar atributos e metoods de outras classe.

Qual a diferença entre private e protected?

nós usamos private para deixar uma informação exclusiva apenas para uma unica classe, já o protected serve para deixar-mos a informação acessivel para todas as classes, mas pra esse contexto usamos para a classe mae que no caso é a "funcionarios.php", qaundo tornamos acessivel podemos acessala com as filhas que são o funcionarioCLT e funcionarioPJ.

O que significa sobrescrever um método?

significa criar uma nova versão do metodo ja criado(na classe mae) na classe filha, sendo assim podendo definir como o metodo vai funcionar na classe filha filha.
